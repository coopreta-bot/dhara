# Krishi SOS

Multi-channel emergency triage for crop disease, pests, extreme weather, and livestock, with escalation to a human.

Guardrail: A severe alert always escalates to a human. The model never replaces an agronomist or vet.

Tools and data scope are declared in `manifest.yaml`. The orchestrator loads that file; this README is the human summary.

Status: OPEN. The skill is not implemented.
