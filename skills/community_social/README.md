# Community and Social Layer

Moderated farmer-to-farmer Q&A. Dhara fact-checks before an answer reaches other farmers.

Guardrail: Nothing is published to other farmers until a human moderator accepts it. Accepted Q&A may later enter RAG.

Tools and data scope are declared in `manifest.yaml`. The orchestrator loads that file; this README is the human summary.
