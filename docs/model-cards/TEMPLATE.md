# Model cards

A model is not promotable without a card in this folder. A public-data connector (satellite, mandi prices) gets a **source card** here too: provenance and access terms, not training lineage.

## Required fields

- Name and version
- Base checkpoint and license
- Dataset versions and the DPDP record ids
- Dhara-Bench score and the general-chatbot baseline on the same holdout
- Known failures
- Status, using only the words in `GOVERNANCE.md`
- Evidence link (eval output path, review record). A prose claim with no artifact stays OPEN
